# Руководство: Создание офлайн-карты для Femto Car Launcher через BBBike

Это подробное практическое руководство объясняет, как создать и установить офлайн-карту и навигацию **для любого города или региона мира** в Femto Car Launcher с помощью бесплатного сервиса **BBBike**.

---

## 1. Как устроена офлайн-навигация в Femto

Femto Car Launcher использует две независимые офлайн-компоненты:
1. **`valhalla_tiles.tar` (Граф дорог и маршрутизация Valhalla C++)**  
   Архив тайлов высокопроизводительного движка Valhalla. Содержит геометрию дорог, скоростные ограничения, разметку полос, разрешенные маневры и знаки. Маршрут строится прямо на процессоре смартфона за 50–150 мс без интернета.
2. **`map.mbtiles` (Векторная подложка карты)**  
   Единый контейнер векторных тайлов (OpenStreetMap / Protomaps / MapLibre). Обеспечивает отображение дорог, зданий, лесов и рек на экране без подгрузки из сети.

Оба файла хранятся на устройстве в директории:
```
/sdcard/Android/data/io.github.seijikohara.femto/files/maps/
```

---

## 2. Шаг 1: Скачивание выгрузки дорог через BBBike

Сервис **BBBike** позволяет вырезать любую произвольную прямоугольную или полигональную область мира в формате OpenStreetMap PBF.

1. Откройте в браузере сервис выгрузок:  
   👉 **[https://extract.bbbike.org/](https://extract.bbbike.org/)**
2. На карте найдите свой город или область.
3. В левой панели настройте параметры:
   - **Name of area:** введите имя на латинице (например: `samara`, `kazan`, `almaty`, `moscow`).
   - **Format:** выберите **`Protocolbuffer (PBF)`** (это стандартный сырой бинарный формат OpenStreetMap `.osm.pbf`).
   - **Your e-mail address:** укажите ваш действующий e-mail (туда придет ссылка на скачивание).
4. Нажмите кнопку **`resize or drag the bounding box`** на карте и рамкой выделите нужную область (город и окрестности).  
   > 💡 *Совет:* Не выделяйте область больше 200–300 км за один раз, чтобы архив скачался быстро и не перегружал оперативную память при конвертации.
5. Нажмите оранжевую кнопку **`extract`**.
6. Через 2–5 минут на вашу почту придет письмо с темой *«BBBike extract ... ready»*.
7. Перейдите по ссылке из письма и скачайте файл (например, `planet_53.19,50.10.osm.pbf`).

---

## 3. Шаг 2: Сборка `valhalla_tiles.tar`

Для преобразования `.osm.pbf` в архив навигационных тайлов `valhalla_tiles.tar` используйте скрипт `build_from_bbbike.py`, входящий в состав репозитория:

### Вариант А: Через Docker (Рекомендуемый, работает на Windows/Mac/Linux без сборки C++)
1. Установите и запустите [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. В командной строке выполните:
   ```bash
   python tools/offline_maps/build_from_bbbike.py path/to/your_downloaded_file.osm.pbf
   ```
   Скрипт автоматически скачает официальный образ Valhalla, нарежет дорожный граф и упакует его в `valhalla_tiles.tar`.

### Вариант Б: Прямой запуск Docker (в 1 команду)
Если вы хотите запустить Docker напрямую в папке с вашим PBF-файлом:
```bash
# Windows PowerShell
docker run --rm -v ${PWD}:/custom_files ghcr.io/gis-ops/docker-valhalla/valhalla:latest

# Linux / macOS
docker run --rm -v $(pwd):/custom_files ghcr.io/gis-ops/docker-valhalla/valhalla:latest
```
В текущей папке появится готовый файл `valhalla_tiles.tar`.

## 4. Шаг 3: Получение векторной подложки (`map.mbtiles`)

Чтобы карта рисовалась на экране офлайн:
1. Скачайте выгрузку векторных тайлов в формате **MBTiles**:
   - Официальные сборки Protomaps / OpenFreeMap: [https://maps.protomaps.com/builds/](https://maps.protomaps.com/builds/)
   - Либо воспользуйтесь утилитой `pmtiles extract` для вырезки нужного региона из глобального файла `planet.pmtiles`:
     ```bash
     pmtiles extract https://build.protomaps.com/20240101.pmtiles map.mbtiles --bbox=minLon,minLat,maxLon,maxLat
     ```
2. Переименуйте полученный файл в `map.mbtiles`.

---

## 5. Шаг 4: Загрузка файлов на телефон

1. Подключите телефон к компьютеру по USB (в режиме «Передача файлов / MTP») или через `adb`.
2. Скопируйте оба файла в папку приложения:
   ```bash
   adb push valhalla_tiles.tar /sdcard/Android/data/io.github.seijikohara.femto/files/maps/valhalla_tiles.tar
   adb push map.mbtiles /sdcard/Android/data/io.github.seijikohara.femto/files/maps/map.mbtiles
   ```
3. Перезапустите Femto Car Launcher.

При запуске лаунчер автоматически обнаружит офлайн-пакет и активирует нативный движок Valhalla C++.

---

## 6. Будет ли навигатор правильно работать для других городов?

**Да, на 100%!**

### Что работает полностью автономно (без интернета):
- **Построение маршрутов:** Движок Valhalla скомпилирован на C++ под архитектуру ARM64 и производит расчет маршрутов локально в оперативной памяти устройства за доли секунды.
- **Голосовые подсказки и маневры:** Подсказки «Через 300 метров поверните направо», расчет расстояния, перестроения, съезды с кольцевых развязок работают полностью автономно.
- **Автоматический перерасчет (Reroute):** Если вы пропустили поворот или свернули с маршрута, навигатор за 100 мс мгновенно пересчитывает новый маршрут от текущей точки GPS.
- **Отображение карты:** Векторные тайлы рендерятся плавно со скоростью 60 кадров/сек прямо из файла `map.mbtiles`.
- **Поиск по координатам и избранным точкам:** Точки «Дом», «Работа», сохраненные адреса и прямой ввод координат (например: `53.2001, 50.1500`) строят маршрут мгновенно офлайн.

### Как работает текстовый поиск адресов (геокодинг):
- Поиск произвольных текстовых строк вроде *«ул. Ленина 45»* при наличии интернета обращается к онлайн-базе OpenStreetMap (Nominatim / Geocoder), подтягивает точные координаты здания и передает их локальному Valhalla-движку для офлайн-ведения по маршруту.
- Если интернета в данный момент нет, маршрут можно задать кликом по карте, выбором из сохраненного «Избранного» или вводом координат.
